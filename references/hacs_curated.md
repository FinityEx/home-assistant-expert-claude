# Curated HACS List (2025/2026)

## Essential Integrations (Backend)
1.  **Adaptive Lighting**: Automatically adjusts light temp/brightness. *Must-have.*
2.  **Alarmo**: DIY security system logic.
3.  **Powercalc**: Virtual power metering for devices without it.
4.  **Spook**: "Not a HACS integration" - powerful diagnostics and helpers.
5.  **Local Tuya / Tuya Local**: Cloud-free control for Tuya devices.
6.  **Frigate**: NVR integration (requires Frigate server).
7.  **Browser Mod**: Make your browser a controllable entity (popups, TTS).

## Essential Frontend (Lovelace)
1.  **Mushroom Cards**: The standard for modern UI.
2.  **Bubble Card**: Mobile-friendly, pop-up centric cards.
3.  **Mini Media Player**: Compact and powerful media controls.
4.  **Auto Entities**: Auto-populate cards based on filters.
5.  **Card Mod**: CSS styling for cards.
6.  **Plotly Graph**: Interactive, high-performance graphs.

## Installation Tip
Always install HACS first if not present. Use the `wget` installation script for Supervised/OS installs.
